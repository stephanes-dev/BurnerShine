# BurnerShine

Serves containerized databases with configurable backup and restore functionality for developers and IT administrators.

BurnerShine is built to be simple and practical, focusing on doing one thing well.

**Why BurnerShine?**

- Serves containerized databases with configurable
- backup and restore functionality for
- developers and IT administrators

## Key Features

- Serves containerized databases with configurable
- backup and restore functionality for
- developers and IT administrators

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/BurnerShine.git`
2. `cd BurnerShine`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
